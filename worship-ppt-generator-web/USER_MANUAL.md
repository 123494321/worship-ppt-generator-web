# ⚡ [1부] 3분 완성 퀵 스타트 가이드 (실전 작업 순서)

처음 프로그램을 사용하시더라도 아래 **6단계 작업 순서**만 따라 하시면 3분 안에 완벽한 찬양 PPT가 완성됩니다.

```mermaid
flowchart LR
    S1["1. 프로그램 실행"] --> S2["2. 프리셋 선택<br/>(청년부 등)"]
    S2 --> S3["3. 콘티 입력<br/>(카톡 복사)"]
    S3 --> S4["4. [기획안 생성] 클릭"]
    S4 --> S5["5. 검토 후<br/>[PPT 파일 생성] 클릭"]
    S5 --> S6["6. [폴더 열기]로<br/>탐색기에서 파일 확인!"]
```

---

### Step 1. 프로그램 실행
* 바탕화면의 **`LOGOS 찬양 PPT 스튜디오`** 아이콘을 더블 클릭하여 실행합니다.
  *(※ 윈도우 PC 보호 창이 뜰 경우: [추가 정보] ➔ [실행] 클릭)*

### Step 2. 사이드바에서 기준 서식 선택
* 화면 왼쪽 사이드바의 **[📁 기준 PPT 설정]**에서:
  * **`교회 표준 프리셋 선택`**을 누르고 등록된 부서(예: **`청년부`**)를 선택합니다.
  * *(프리셋이 없거나 내 컴퓨터의 PPT 서식을 쓰고 싶다면 `내 PC에서 직접 업로드`를 누르고 .pptx 파일을 올리세요 ➔ [상세 1])*

### Step 3. 1단계: 콘티 입력창에 콘티 넣기
* 상단 **`1. 콘티 작성`** 탭의 넓은 텍스트 창에 준비된 콘티를 붙여넣습니다.
* **작성 필수 규칙 3가지만 기억하세요:**
  1. 예배 날짜/모임명: 맨 첫 줄에 `# 2026.09.13 LOGOS 청년 모임` 형태로 작성
  2. 대표기도자: `기도: 홍길동 청년`
  3. 곡 시작: `## 1. 꽃들도`
  4. **슬라이드 나누기**: **가사 사이를 한 줄 띄우면(엔터 2번)** 자동으로 다음 슬라이드로 넘어갑니다!  
  *(※ 더 상세한 콘티 문법이나 악보 순서 작성법은 ➔ [상세 2], [상세 7] 참고)*

### Step 4. [PPT 기획안 생성 ➔] 버튼 클릭
* 화면 하단의 파란색 **`[PPT 기획안 생성 ➔]`** 버튼을 누릅니다.
* 콘티에 적힌 곡들이 찬양곡 라이브러리에 자동으로 저장되며, **`2. PPT 기획안`** 탭으로 자동 이동합니다.

### Step 5. 2단계: 슬라이드 검토 후 [PPT 파일 생성] 클릭
* 슬라이드 번호(1, 2, 3...)와 가사 순서를 눈으로 가볍게 확인합니다. 오탈자가 있다면 메모장처럼 직접 수정하실 수 있습니다. *(➔ [상세 4])*
* 확인이 끝났다면 하단의 **`[PPT 파일 생성]`** 버튼을 클릭합니다! (3~5초 만에 생성 완료)

### Step 6. 파일 확인 및 예배 준비 완료!
* 화면에 뜬 **`[💾 PPT 파일 다운로드]`** 버튼을 눌러 USB에 바로 저장하거나,
* 상단의 **`3. 클라우드 보관소`** 탭을 클릭한 뒤 **`[📂 폴더 열기]`** 버튼을 누르면 **윈도우 파일 탐색기가 즉시 열리며 완성된 PPT 파일을 바로 사용**하실 수 있습니다! *(➔ [상세 5])*
* *(동시에 텔레그램 공식 채널로도 자동 업로드되어 찬양팀 스마트폰으로 바로 공유됩니다)*

### [상세 1] 사이드바 기준 PPT 및 표지 이미지 설정
1. **기준 PPT 지정 방식**:
   - `교회 표준 프리셋 선택`: 텔레그램 클라우드에 등록된 공인 부서(`청년부`, `중고등부` 등)의 공식 서식을 클릭하여 적용합니다.
   - `내 PC에서 직접 업로드`: 로컬 PC의 `.pptx` 파일을 올려 해당 파일의 폰트, 여백, 상하좌우 배율을 그대로 복제합니다.
2. **표지 이미지 설정**:
   - `프리셋 기본 표지 사용`: 선택된 부서의 대표 표지(16:9 와이드스크린)를 1번 슬라이드에 꽉 차게 자동 삽입합니다.
   - `이번 주만 임시 교체`: 절기 행사나 특별 예배로 표지를 바꾸고 싶을 때 새 이미지(`.png`, `.jpg`)를 업로드합니다.
   - `➕ 크게 보기`: 등록된 표지 이미지를 고해상도 팝오버 창으로 미리 선명하게 확인합니다.

### [상세 2] 콘티 필수 작성 문법 및 규칙 완전 정복
| 구분 | 문법 규칙 | 작성 예시 | 동작 결과 |
| :--- | :--- | :--- | :--- |
| **표지 정보** | `# [날짜] [모임명]` | `# 2026.09.13 LOGOS 청년 모임` | 1페이지 표지 슬라이드 자동 생성 |
| **대표기도자** | `기도: [이름]` | `기도: 홍길동 청년` | 찬양 종료 후 마지막 대표기도 슬라이드 생성 |
| **곡 시작** | `## [번호]. [곡 제목]` | `## 1. 꽃들도` | 곡 시작 선언 및 제목 슬라이드(`[ 꽃들도 ]`) 생성 |
| **악보 루틴** | `루틴: [진행 순서]` | `루틴: Intro(8) - V1 - C - C - Outro` | 악보 순서에 맞춰 가사 슬라이드를 순방향 자동 전개 |
| **파트 선언** | `[파트명]` | `[V1]`, `[V2]`, `[P]`, `[C]`, `[B]` | 절(Verse), 프리코러스, 후렴, 브릿지 등 파트 선언 |
| **슬라이드 분할**| **빈 줄 하나 (엔터 2번)** | *(가사 문장 사이 빈 줄)* | **빈 줄이 들어가면 다음 슬라이드로 넘어감** |

* **줄 바꿈 요령**: 한 슬라이드에 2줄 가사를 넣으려면 엔터를 1번만 치고, 다음 슬라이드로 넘기려면 엔터를 2번(빈 줄 하나) 칩니다.
* **실시간 자동 저장**: 글자를 입력할 때마다 브라우저 로컬 저장소와 서버에 실시간 자동 동기화되므로 별도의 저장 단축키를 누를 필요가 없습니다.
* **임시저장본 1초 복구**: 인터넷이 끊기거나 창을 실수로 닫더라도, 에디터 상단의 **`[📥 임시저장본 복구]`** 버튼을 누르면 직전 작업 내용이 100% 즉시 복구됩니다.

### [상세 3] 과거 찬양곡 라이브러리 검색 및 1초 교체
* 사이드바의 **`[📚 찬양곡 라이브러리 검색]`** 창에 곡명(예: `꽃들도`)을 입력하면 과거에 제작했던 곡이 나타납니다.
* **`[1번 교체]`**, **`[2번 교체]`**: 현재 콘티의 해당 순서 곡을 라이브러리에 저장된 가사와 루틴으로 즉시 1:1 교체합니다.
* **`[➕ 콘티 끝에 추가]`**: 콘티 맨 끝에 해당 찬양곡을 바로 이어 붙입니다.

### [상세 4] 슬라이드 기획안 IDE 에디터 활용법 (휴먼 게이트)
* 1단계에서 **`[PPT 기획안 생성 ➔]`** 버튼을 누르면 2단계 기획안 탭으로 이동합니다.
* 좌측에 슬라이드 번호(1, 2, 3...)가 라인별로 표시되어 전체 구성을 한눈에 볼 수 있습니다.
* 가사 오탈자를 고치거나, 필요한 위치에 암전(`[BLANK]`)을 넣거나 빼는 작업을 자유롭게 할 수 있습니다.

### [상세 5] 4대 로컬 데이터 보관함 자동 저장 구조
`[PPT 파일 생성]`을 누르면 아래 4개 폴더에 데이터가 자동으로 분류되어 영구 보관됩니다:
1. **`데이터 보관함/1_기준_PPT_프리셋/`**: 부서별 공식 기준 PPT와 최신 표지 이미지 보관
2. **`데이터 보관함/2_찬양_PPT/`**: 완성된 주차별 완성본 PPTX 파일 자동 보관 (`[청년부][PPT][제목][날짜].pptx`)
3. **`데이터 보관함/3_찬양곡_라이브러리/`**: 개별 찬양곡 가사 및 루틴 JSON 파일 자동 적재
4. **`데이터 보관함/4_찬양_콘티/`**: 작성된 콘티 원본 텍스트 자동 백업
* **보관소 탭 연동**: `3. 클라우드 보관소` 탭에서 **`[📂 폴더 열기]`**를 누르면 윈도우 탐색기로 위 폴더가 즉시 열립니다.

### [상세 6] 관리자 가이드: 스마트폰 텔레그램 원격 관리
관리자는 PC를 켜지 않고도 스마트폰 텔레그램 채널에서 서식을 직접 등록/교체할 수 있습니다.
1. **신규 부서 프리셋 추가**:
   - 일반 텍스트로 **`#추가 : 중고등부`** 전송 ➔ 봇이 카탈로그에 등록하고 PC에 폴더 자동 생성
2. **기준 PPT 교체/등록**:
   - `.pptx` 파일 첨부 + 캡션에 **`#기준`** 작성 전송 ➔ 봇이 띄워주는 부서 버튼(`[1. 청년부]`) 클릭
3. **표지 이미지 교체/등록**:
   - 사진 첨부 + 캡션에 **`#표지`** 작성 전송 ➔ 봇이 띄워주는 부서 버튼 클릭 ➔ PC 사이드바에 실시간 반영

### [상세 7] 악보 루틴(진행 순서) 표기법 일람표
| 표기 형식 | 인식 의미 | 자동 생성 슬라이드 |
| :--- | :--- | :--- |
| `Intro(8)`, `전주` | 시작 전주 | 암전 옵션에 따라 `[BLANK]` 암전 슬라이드 생성 |
| `(1)`, `(2)`, `(4)`, `(8)` | 마디 수 간주 | **가사 없이 비우는 `[BLANK]` 암전 슬라이드 생성** |
| `I(8)`, `간주`, `Solo` | 간주 연주 | **`[BLANK]` 암전 슬라이드 자동 생성** |
| `(기도)`, `(멘트)`, `(묵상)` | 멘트/기도 | **`[BLANK]` 암전 슬라이드 자동 생성** |
| `Cx2`, `Bx4` | 파트 연속 반복 | 해당 파트 가사를 **2회 / 4회 연속으로 순방향 전개** |
| `C(잔잔)`, `(인도자)V` | 연주/보컬 뉘앙스 | 수식어를 제외하고 기본 `C`, `V` 파트 가사 매칭 |
| `C'`, `C’` (Key-up) | 조바꿈 후렴 | 1차로 `[C']` 파트 탐색, 없으면 기본 `[C]` 자동 적용 |
| `Tag`, `[TAG]` | 마무리 태그 | `[TAG]` 파트 우선 매칭, 없으면 **후렴(`[C]`) 마지막 슬라이드 적용** |

### [상세 8] 자주 묻는 질문 (FAQ) & 문제 해결
* **Q1. 폰트가 깨지지 않나요?**  
  기준 PPT 원본의 임베디드 폰트와 레이아웃을 1:1로 딥클론하므로 어떤 PC에서도 동일한 폰트와 배율로 투사됩니다.
* **Q2. 인터넷이 끊기면 못 쓰나요?**  
  프로그램 상단에 `⚪ 오프라인 모드`가 뜨며, 로컬 컴퓨터에서 PPT 제작과 탐색기 열람이 100% 정상 작동합니다.
* **Q3. 업데이트 설치 시 기존 파일이 지워지나요?**  
  설치기에 `onlyifdoesntexist` 보호가 적용되어 있어, 재설치하더라도 사용자의 소중한 보관함 데이터는 절대 덮어씌워지거나 삭제되지 않습니다.
